# SQL-pizza-sales
This project analyzes pizza sales using SQL.
The dataset includes orders, pizza types, sizes, categories, and pricing.
 Tools Used
MySQL 
Joins
Aggregations
CTE

 Key Insights
Total orders: 21,350 
Total revenue: $817,860 
Highest-priced pizza: The Greek Pizza ($35.95) 
Most ordered size: Large (18,526 orders) 
Top 5 pizzas by quantity sold include Classic Deluxe & Barbeque Chicken 
Peak order hour: 12 PM 
Top revenue pizzas: Thai Chicken, Barbeque Chicken, California Chicken

Cleaning and analyzing relational data
Finding revenue drivers
Writing clean SQL queries.
